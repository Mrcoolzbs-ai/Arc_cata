# Проверки 0.6.0-cinematic-preview

Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21. Linux, Xvfb, Mesa llvmpipe; программный OpenGL. Проверены исходники этой локальной сборки. Это не пользовательский GPU-бенчмарк и не разрушительный стресс-тест.

## Чистая сборка

`./gradlew clean build` без QA-флагов: PASS. Проверены версия JAR, наличие новых классов/шейдеров, JSON, отсутствие QA-классов, совпадение хешей 30 новых аудиоресурсов с манифестом. Три предупреждения deprecated API остаются; ошибок компиляции нет. JAR одинаковый для клиента/сервера.

## Автономные контракты

`./tools/tests/run.sh`: 58 881 проверка ImpactDynamics и контракт горизонтальных печатей/камеры/настроек: PASS.

`python3 tools/tests/test_cinematic_contract.py`: scope 1–15 / epic 10–15, частный preview без серверного каста, запрет End of All, отсутствие нитей игрок→цель, 30 локализованных глав, 30 stereo Vorbis-файлов, длительности и хеши: PASS.

Каталог Spell, ImpactDynamics, DestructionEngine, DestructionPlan, PreparedChunk, EndEvent, EndSchedule, SpellNetwork, EndCinematic, обе звуковые дорожки End of All и end_scene.fsh сверены с началом работы — побайтово неизменны. SpellManager изменён только в ограничении/подсказках preview (1–15 вместо 1–5).

## Настоящий клиент

Первый прогон `./gradlew runClient -Pstyleqa -Pstylecommandqa`: все 15 заклинаний, по 16 кадров (240). Затем финальный прогон диапазона 4–15:

```sh
./gradlew runClient -Pstyleqa -Pstylecommandqa -Pstylefrom=3
```

По 18 кадров (216): вступление, 18/40/62/84% до импакта, -2/0/+2/+5/+8/+14/+26/+55/+100 тиков, отдельные отключения flash/glitch/shake. Всего два обычных прогона дали 456 реальных framebuffer-кадров. Финальный прогон включает исправленные лаву/воду, движение внутрь собора и чистый HUD без учебной подсказки.

Команды прошли диспетчер интегрированного сервера и реальный сетевой FX-пакет. Проверены запрет preview оператору недостаточного уровня, запрет preview End of All, отсутствие задания разрушения/EndEvent/перезарядки, opt-out CAMERA/ASTRAL/skip и отключение тряски. Запущены оба модовых шейдера invocation/saga, без ошибок их компиляции/линковки. Отсутствующая системная библиотека narrator/flite — предупреждение среды, а не ошибка модового рендера.

Компактный отдельный прогон:

```sh
./gradlew runClient -Pstyleqa -Pstylecompact -Pstyleonly=14
```

Окно 960×720, GUI scale 3, эффективный GUI 320×240 проверен утверждением. 18 кадров Приговора мироздания, включая пять глав/импакт/настройки отключения. Это не просто выставленный scale в слишком маленьком окне.

Кадры previews/cinematic-0.6 скопированы из настоящего framebuffer. Промежуточные GLSL/WebGL-контрольные рендеры использовались для художественной итерации; они не подменяют игровые кадры. Визуально проверены характерные виды новых сцен, интерфейс и найденные дефекты исправлены. Полный автоматический набор кадров не является заявлением ручной оценки каждого пикселя.

## Серверная регрессия

`./gradlew runServer -Pv4pure`: загрузка dedicated server, 326 717 колонок геометрии, 5 676 710 замен блоков, распределение 1–240 участников, шесть волн 9/17/21/25/29/42 секунд, round-trip EndState: PASS. Тест вышел до создания мира. Нового испытания разрушения миллионов блоков, живого удалённого мультиплеера, модпаков/шейдерпаков и коррекции низкого TPS не заявляется.

## Аудио и автономное превью

30 новых дорожек декодированы FFmpeg; подтверждены stereo, длительности charge до импакта и 8-секундные impact, измерены integrated LUFS / true peak / LRA (docs/AUDIO_QA_0.6.json). Цифрового клиппинга по проверке нет. Это оригинальный синтез музыкальных/шумовых тембров, не запись живого оркестра. Техническая проверка не заменяет прослушивание на колонках/наушниках и художественный отзыв пользователя. Игровой QA удерживает возраст кадра; это не тест нормального аудиосинка или акустики.

Отдельный HTML содержит конечные шейдеры и встроенные новые звуки без внешних запросов. Проверены WebGL-компиляция, пользовательский запуск аудио, desktop и ширина 390 px без горизонтального переполнения. Это шейдерное превью без Minecraft/HUD/реального мира, не запись клиента и не FPS-бенчмарк.

## Осторожно

Настоящие касты опасны. Для оценки используйте только `/cataclysm preview <id>` (1–15). `destruction=false` не отключает урон. Касты/разрушение и механика бедрока не переработаны, End of All сохранён. Нет undo и сохранения незавершённых очередей после рестарта.
