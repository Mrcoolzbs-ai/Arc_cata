Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21, Linux, Xvfb/Mesa llvmpipe. Это функциональные проверки программного OpenGL, не FPS-бенчмарк пользовательской видеокарты. Дата запуска: 2026-10-24 UTC.

- 326 717 колонок, 5 340 156 замен блоков: границы высот, неизменность снимка, защищённые состояния, совпадение подготовленных патчей с чистым планом.

- 3 095 состояний воды: цели y=-60/0/60/200, minY=-128/-64/16, scale=.1/1/1.5. Вода только над дном до y=0 включительно; выше — воздух; при дне выше 0 заполнения нет.
- EndSchedule для 1–240 участников, волны 9/17/21/25/29/42 секунды, длительность 45 секунд, round-trip EndState: PASS.

`./gradlew runServer -Pfilmserverqa --no-daemon`: PASS, отдельный одноразовый плоский мир. Подготовка: `tools/qa-presets/pipeline-server.properties` → `run-filmserver/server.properties`, `eula=true`; мир не должен содержать ценные данные. Тестовый сервер слушает только localhost.

- Падение жизни scale=.1, центр y=60: до release изменений нет, подготовлено 32 чанка. При `instantImpact=true` сразу после release 0 изменённых блоков / 0 burst-чанков.
- Далее очередь завершилась: 53 588 изменённых блоков, 24 изменённых чанка, failed=0/skipped=0; jobs=0/lighting=0. Деревянной надстройки нет. Ещё 40 тиков: очередь пуста, счётчик изменений не растёт.
- Бездна прилива scale=.1, центр y=-40: 636 784 изменений, 32 чанка; реальные блоки в центральной колонке — вода y=-58..0, воздух y=1..60. После завершения очередь пуста.
- Отмена Падения жизни в подготовке завершается без оставшейся задачи.

Это **не** стресс-тест полного радиуса 352/416, не удалённый мультиплеер, не тест на всех модпаках и не доказательство отсутствия любого лага. Генерация тысяч чанков и применение большого разрушения всё ещё требуют работы; очередь не исчезает до завершения. Уже созданные старой версией деревянные структуры не удаляются автоматически.

## Откуда сокращение нагрузки Падения жизни

`python3 tools/tests/life_geometry_budget.py` воспроизводит формулы диапазона колонок 0.6.0 (`3d1a460`) и 0.6.1 на **плоской местности y=60, центр y=60, minY=-64/maxY=320, scale=1, radius=352**:

| Метрика работы | 0.6.0 | 0.6.1 |
|---|---:|---:|
| Колонки в круге | 389 284 | 389 284 |
| Состояния в диапазонах снимков | 59 021 660 | 31 671 680 |
| Ячейки надстроек выше исходной поверхности | 533 780 | 0 |

Это детерминированный расчёт количества ячеек, **не** замер FPS, времени или выделенной памяти. Материалы/регистры/освещение/генерация здесь не профилируются. Он не переносится без оговорок на горы, другую высоту/scale или пользовательский мир. Пайплайн дополнительно уступает управление между колонками и запрещает instantImpact-burst для этого заклинания; эти пути проверены отдельными контрактами и маленьким живым кастом выше.

## Реальный клиент и визуальная проверка

Финальные команды:

```sh
./gradlew runClient -Pstyleqa -Pstylecommandqa -Pstylefrom=9 --no-daemon
./gradlew runClient -Pstyleqa -Pstyleworld -Pstylefrom=5 --no-daemon
```

Первый прогон — 6 фильмов × 19 кадров: вступление, 10/28/50/74/91%, до/на/после удара, последствия и opt-out-настройки. Preview проходит настоящий диспетчер интегрированного сервера и сетевой пакет; проверяет отсутствие задания разрушения, EndEvent и cooldown. Внутри фильма проверяется независимый Film-слой и отсутствие перемещения реальной камеры; после V/отключения — выход из фильма и остановка score.

Второй прогон — 10 мировых эффектов × 19 кадров, CAMERA/ASTRAL/POST выключены, GUI скрыт; камера смотрит на цель с трёхчетвертного ракурса, вода отдельно на y=0; дальность 10 чанков и 200 тиков ожидания для загрузки местности. Применяются матрицы model-view/projection самого события NeoForge и восстанавливаются после рисования. Это реальный AFTER_PARTICLES-рендер, а не шейдерная сцена вместо мира. Preview не изменяет блоки: фактическая вода проверяется dedicated-server тестом выше.

Контактные листы и избранные кадры — `previews/cinematic-0.6.1/`. Они взяты из настоящего framebuffer; листы служат визуальной проверке, а не доказательством темпа видео/аудиосинка. Фильмы просмотрены по ключевым стадиям; весь автоматический набор не означает ручной оценки каждого пикселя. Пропуск, CAMERA/ASTRAL, отключение shake проверены утверждениями QA. Ресурсные программы всех шести фильмов проходят OpenGL-компиляцию/линковку. Отсутствие narrator/flite — известное предупреждение среды, не ошибка модового шейдера.
