# Постановка 0.6

## Режиссёрские правила

1–9: близкий план персонажа с локальными печатями → отдельная объёмная сцена → возврат к реальному импакту. Никаких соединяющих игрока с целью нитей. 10–15: короткое вступление → самостоятельный фильм со своим окружением и пятью главами → постановочный удар/последствия → растворение в игровом мире. Ни один фильм не создаёт блоки или сущности.

## Техническая карта

- `InvocationDirector`: scope 1–15, 10–15 epic, плавное открытие и закрытие фильма, близкая реальная камера остаётся около игрока.
- `invocation.fsh`: постановки 1–9; отдельные алгоритмы каждого объекта.
- `saga.fsh`: самостоятельные истории 10–15, аналитические лучи/боксы/капсулы/сферы, отдельные траектории камеры. Волна и лава используют уточнение пересечения, чтобы слои выборки не были видимыми ступенями.
- `FirstFiveRenderer`: первые пять мировых постановок, новая буря, без нитей.
- `SecondFourRenderer`: мировые аналоги 6–9.
- `InvocationHud`: 30 локализованных заголовков глав, защищённая верхняя полоса, индекс XV.
- `MusicMixin`: обычная музыка не возобновляется поверх активной катсцены; при начале каста собственного персонажа текущая музыка останавливается. Плеер End of All не менялся.
- `SpellManager.preview`: частный FX-пакет для 1–15, запрет End of All, без серверного разрушения/урона.

Сага входит примерно с 24-го тика. Возврат начинается через 50 тиков после импакта и занимает 32 тика. У 1–9 возврат по-прежнему начинается перед импактом. Художественная сцена не является доказательством окончания серверного редактирования чанков.

## Аудио

Оригинальные синтезированные мелодии, гармонические главы, бас, тембры струнных/меди/органа/флейты/колоколов/хора и индивидуальные материальные жесты. 32 kHz, stereo Vorbis. Charge: точно 18/20/21/22/21/23/24/25/26/29/31/33/35/37/40 секунд; impact: 8 секунд. Сохранена существующая задержка звука удара по дистанции, музыка каста завершается на импакте. Нормализация FFmpeg: target -20 LUFS charge / -17 LUFS impact, TP -2 dB; окончательные метрики нужно смотреть в аудио-QA, а не считать target измерением.

Параметры и мотивы в tools/generate_v6_audio.py. Стереорефлексы создаются без внешних семплов. Конец всего сохранён побайтово.
