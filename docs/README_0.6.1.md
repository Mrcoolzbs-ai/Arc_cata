# Arcane Cataclysm 0.6.1-cinematic-rework

Minecraft 1.21.1 · NeoForge 21.1.264 · Java 21. Один JAR для клиента и сервера; протокол 4 сохранён.

## Исправления 0.6.1

- **10–15 теперь идут отдельным непрозрачным полноэкранным слоем**, как самостоятельная анимационная вставка, а не через InvocationHud/ритуальные рамки 1–9. Нет индекса, фазы, астролябий, прогресс-бара, подсказки пропуска или интерфейса паузы поверх фильма. Реальная камера не переносится к цели.
- У каждого фильма **шесть монтажных планов**: предзнаменование, деталь, раскрытие масштаба, действие, кульминация, последствия. Город разрушается под падающим чёрным солнцем; лес и древо угасают; собор вырастает и открывает проход, камера входит внутрь; прилив накрывает город и уводит камеру под воду; материк раскалывается; приговор стирает город рядами.
- **Шесть новых цельных stereo-партитур**, 34/36/38/40/42/45 секунд: музыка продолжается через удар и пять секунд последствий. Струны, хоровые тембры, гармоническое развитие, ведущая тема, перкуссия и стихиевые шумы синтезированы без внешних семплов. Это не живой оркестр. Музыка фильма — громкость «Музыкальные блоки/проигрыватели» (`RECORDS`), мир — «Игроки» (`PLAYERS`). Локальная партитура не накладывается на старые charge/impact. Старые дорожки 1–15 остаются для мирового просмотра.
- **Мир больше не использует старый RitualRenderer для 10–15.** Убраны мечи из Бездны прилива, лишние печати из Последнего катаклизма/Приговора мироздания. У последнего ровно одна верхняя печать и восемь каменных монолитов.
- Мировой FX-рендер теперь применяет и восстанавливает матрицы model-view/projection из события NeoForge: объекты следуют реальному yaw/pitch камеры, а не глобальной матрице RenderSystem.
- **Разлом титанов:** низкие приземлённые плиты вдоль направления разлома вместо плавающих столбов/кристаллов. **Солнечная нова:** удалены длинные солнечные ленты и в фильме каста, и в мире.
- **Падение жизни:** один ограниченный по геометрии материальный образ древа вместо полупрозрачных корней; все мировые эффекты 10–15 прекращаются через 80 тиков после удара. Больше не создаются постоянные гигантские деревянные/моховые надстройки; остаётся бесплодный кратер с rooted/coarse dirt. Уже созданные старой версией конструкции автоматически не удаляются.
- Для Падения жизни снимок чанка собирается **по колонкам с проверкой бюджета**, отмена освобождает билет незавершённого снимка. Небюджетированный `instantImpact`-рывок этому заклинанию не применяется даже при включённой настройке; разрушение продолжается очередью. Радиус, глубина кратера, время удара и урон не уменьшены.
- **Бездна прилива: настоящие блоки воды заполняются до y=0 включительно**, только над дном кратера, независимо от высоты прицеливания. Выше 0 вода не создаётся. Если дно выше 0, заполнения водой нет. Визуальный прилив также привязан к y=0.
- Процедурные фильмы ограничены 960×540 (с сохранением пропорций) и разнесены на шесть GPU-программ; скрытый за фильмом мировой FX-рендер не выполняется. Это ограничение стоимости, не обещание FPS на любой видеокарте.

**«Конец всего»: музыка, шейдер, клиентская сцена, серверная механика и расписание не менялись. Нити игрок→цель не возвращены.**

## Безопасно посмотреть

Оператор, уровень прав 2, от игрока:

```text
/cataclysm preview tectonic_rift
/cataclysm preview solar_nova
/cataclysm preview last_cataclysm
/cataclysm preview verdant_ruin
/cataclysm preview obsidian_cathedral
/cataclysm preview abyssal_deluge
/cataclysm preview world_sunder
/cataclysm preview rune_apocalypse
```

Preview доступен для 1–15; он не создаёт разрушение, урон, перезарядку или EndEvent. «Конец всего» исключён. Для фильмов включите `cinematicCamera`, `astralScenes`, `postProcessing`. **C** — отключить камеру/фильм, **V** — пропустить представление; серверный каст не отменяется. После отключения и повторного включения камеры партитура не стартует с начала посреди сцены. `screenFlash` сохранён; новые фильмы не используют строб. 1–9 сохраняют ритуальную подачу. Чтобы смотреть мировой эффект без фильма, отключите C.

**Настоящие касты опасны и разрушают огромную область.** Делайте резервную копию мира. `destruction=false` не отключает урон. Бедрок может разрушаться у 10–15, если разрешён серверной настройкой. Не проводите сравнение эффектов настоящими кастами в ценном мире. У очередей нет undo и восстановления незавершённых задач после рестарта.
