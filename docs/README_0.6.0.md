# Arcane Cataclysm 0.6.0-cinematic-preview

Minecraft 1.21.1 · NeoForge 21.1.264 · Java 21. Одинаковый JAR на клиенте и сервере. Протокол 4 сохранён.

## Этот выпуск

- Новые постановки 6–9: **Разлом титанов**, **Адский прилив**, **Сингулярность**, **Солнечная нова**. Сохранены ритуальные печати и материальные объекты первой пятёрки; добавлены мировые эффекты для наблюдателей.
- **Гнев бури** полностью переставлен: восходящий полый вихрь, вращающиеся облачные рукава, обходящие воронку разряды и финальная разветвлённая молния вместо плоского облачного венца.
- **10–15 — отдельные пятиглавные процедурные фильмы**: катаклизм над городом, угасание древа, пробуждение собора, затопление города, раскол континента и руническое стирание. У каждой истории свои движение камеры, окружение, развитие и последствия. Это не просто другой цвет одной сцены каста.
- Нити от персонажа к цели удалены. Локальные печати около игрока и эффекты в области цели сохранены.
- Для **1–15** созданы 30 новых стереодорожек: цельная музыкально-шумовая композиция до удара и отдельный удар с музыкальным разрешением/хвостом. Это оригинальный детерминированный синтез, без внешних семплов; не запись живого оркестра. Дорожки не зациклены. Композиция и ресурсы **«Конца всего» не изменены**.

Музыкальные характеры: небесная медь/колокола, металлическое остинато клинков, ледяное стекло, грозовые медные/низкие удары, восходящая космическая тема, каменная пульсация, огненные струны, тёмные хоровые тембры сингулярности, солнечная медь, катастрофический реквием, угасающие флейта/струны, соборный орган, подводные тембры, континентальные низкие удары и рунический орган/стекло.

## Безопасный просмотр

Оператор, уровень прав 2; команда работает только от игрока:

```text
/cataclysm preview tempest_wrath
/cataclysm preview tectonic_rift
/cataclysm preview inferno_tide
/cataclysm preview singularity
/cataclysm preview solar_nova
/cataclysm preview last_cataclysm
/cataclysm preview verdant_ruin
/cataclysm preview obsidian_cathedral
/cataclysm preview abyssal_deluge
/cataclysm preview world_sunder
/cataclysm preview rune_apocalypse
```

Preview поддерживает **все 1–15**, только для вызвавшего игрока. Не создаёт серверный каст, разрушение, урон, расход предметов или перезарядку. «Конец всего» исключён. Обычный `/cataclysm cast` и ПКМ остаются опасными. **destruction=false не отключает урон.**

Для полного оформления нужны cinematicCamera=true, astralScenes=true, postProcessing=true. C — камера, V — пропуск. Настройки screenFlash, impactGlitch, screenShake сохраняются. Для 10–15 эти настройки и пропуск действуют так же, как для обычных заклинаний: сцены не копируют принудительную глобальную механику End of All.

## Границы изменения

Каталог, длительности каста/импакта, радиусы, урон, разрушение, бедрок и End of All не усилены и не переработаны. Сцены 10–15 показывают художественные процедурные пространства, **не реальные удалённые чанки**. Вставку видит кастующий; наблюдатели видят мировые эффекты. Высокоуровневый фильм включает постановочный удар и короткие последствия, затем растворяется в реальном мире. Серверный удар всё равно происходит в прежний тик.

Для обычных заклинаний сохранён существующий сетевой тайминг; это не новая коррекция рассинхронизации при низком TPS. Мгновенное применение готовых чанков может вызывать зависания. Нет undo или восстановления незавершённых очередей после рестарта. Реальные касты испытывать только в одноразовой копии мира.

## Разработка

```sh
./gradlew clean build
./tools/tests/run.sh
python3 tools/tests/test_cinematic_contract.py
./gradlew runClient -Pstyleqa -Pstylecommandqa
./gradlew runServer -Pv4pure
python3 tools/package_release.py
```

Аудио воспроизводится из исходников:

```sh
python3 tools/generate_v6_audio.py
```

Скрипт v6 не изменяет End of All. `generate_v4_audio.py` — исторический генератор прежнего выпуска, не команда для регенерации нового сопровождения.
