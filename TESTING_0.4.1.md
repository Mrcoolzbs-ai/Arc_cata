# Проверки 0.4.1

Среда: Minecraft 1.21.1, NeoForge 21.1.264, Java 21. Точные маркеры — в QA_RESULTS.txt.

## Изменения

- В новом серверном конфиге enableEndOfAll=true.
- Операторская команда /cataclysm endofall: чтение состояния, true, false, toggle.
- Значение меняется сразу и сохраняется через ModConfigSpec.save().
- Старый конфиг не переписывается новым значением по умолчанию.
- Код 45-секундного события, сетевой протокол и клиентская катсцена не изменены.

## Новый серверный smoke-тест

`./gradlew runServer -Pv41qa` в отдельной папке run-v41-qa с одноразовым миром. Для первого запуска нужен чистый конфиг. Перед запуском принять Minecraft EULA в этой тестовой папке; не копировать сюда рабочий мир. Для использованной проверки сервер был offline-mode=false, плоский мир, view-distance=2, simulation-distance=2.

На реально загруженном выделенном сервере проверены:
- Новый конфиг создаётся с true.
- Уровни прав 0 и 1 не могут менять настройку; уровень 2 может.
- Команда работает из серверной консоли без игрока.
- Чтение состояния ничего не переключает; неверный аргумент отвергается.
- true/false и оба направления toggle меняют значение и записывают его в активный TOML.
- При false новый каст отвергается.
- При true операторский тестовый персонаж может начать событие.
- Переключение в false и обычный /cataclysm cancel не сбрасывают активное событие и блокировку возрождения.

Этот smoke-тест не проходит всю катсцену: разрушение выключено для тестового каста, затем событие сбрасывается тестовым кодом. Он не является повторным тестом массового разрушения.

В NeoForge 21.1.264 новый конфиг появился в run-v41-qa/config/arcane_cataclysm-server.toml. Файл в world/serverconfig, если существует, переопределяет общий конфиг. Команда сохраняет именно активный конфиг, а не пишет по жёстко заданному пути.

## Перезапуск

После первого smoke-теста значение намеренно сохранено как false. Следующий запуск:

`./gradlew runServer -Pv41qa -Pv41restart`

Проверено, что после полного перезапуска сервер загрузил false, а не заменил его новым default=true. Затем команда true успешно включила настройку и записала true в TOML.

## Повторные pure-регрессии

`./gradlew runServer -Pv4pure`

Повторно пройдены 326717 проверок геометрических колонок и 5676710 состояний замены блоков; распределение групп для 1–240 участников, временные отметки волн 9/17/21/25/29/42 секунды, завершение на 45-й секунде и round-trip кодека EndState.

## Сборка и границы проверки

Релиз собирается отдельно, без -P*qa, через clean build. QA-классы не должны присутствовать в релизном JAR. Версия в метаданных — 0.4.1; ресурсы JSON проверяются парсером.

Полный игровой/визуальный прогон из 0.4.0-preview в этом патче не повторялся. Его результаты сохранены в TESTING_0.4.0-preview.md и QA_RESULTS_0.4.0-preview.txt. Тогда проверены шесть волн, несколько измерений и режимов, возрождение, в том числе doImmediateRespawn=true, и разрушение 131712 блоков в одноразовом мире. Разрушение сотен миллионов блоков не проверялось.

Устанавливать одинаковый JAR 0.4.1 на клиент и сервер. Перед проверкой события обязательно сделать резервную копию мира: отмены изменений и undo нет. Отключение настройки запрещает только новые касты, уже начатый 45-секундный каст не прерывается.
