# Проверки 0.5.1-style-preview

Minecraft 1.21.1 / NeoForge 21.1.264 / Java 21. Визуальная доработка первой пятёрки. История прежнего выпуска: TESTING_0.5.0-style-preview.md и QA_RESULTS_0.5.0-style-preview.txt. Свежие маркеры — QA_RESULTS.txt.

## Объём изменения

Изменены только клиентское оформление, чистая математическая модель ImpactDynamics, QA-хуки, версия и документация. Каталог Spell, длительности/момент импакта, DestructionEngine, DestructionPlan, PreparedChunk, EndEvent, EndSchedule, SpellNetwork и весь рендер «Конца всего» не изменены относительно первого коммита репозитория ae687d4.

- У десяти мест вызова ритуальных seal в invocation.fsh нормаль +Y. Материальный ореол копья теперь также пересекается лучом с XZ-плоскостью. FxMesh.disk в мире уже горизонтален; намеренного наклона горизонта у первой пятёрки больше нет.
- Тряска привязана к импакту, уровню/радиусу/масштабу и дистанции; есть верхний предел и затухание. Цветные помехи ограничены первой пятёркой и окном после удара. Урон, время и разрушение не усилены.
- Новый HUD закреплён на экране и не проходит через шейдер разрывов. Крупная фаза расположена в верхней чёрной полосе, центр сцены свободен.

## Свежие проверки

### Математика и контракт геометрии

```sh
JAVA_HOME=/path/to/java21 PATH=/path/to/java21/bin:$PATH ./tools/tests/run.sh
```

58 881 проверка: нарастание силы первой пятёрки, пределы, масштабы, отсутствие тряски до импакта/после окна, монотонное затухание, ослабление на расстоянии, конечные значения, границы цветного импульса. Дополнительно Python-проверка десяти горизонтальных seal, XZ-ореола, нулевого наклона камеры, uniform и связи с настройками отключения. Это не замена игровому прогону.

### Настоящий Minecraft-клиент

```sh
./gradlew runClient -Pstyleqa -Pstylecommandqa
```

80 кадров, по 16 на каждое заклинание: пролог, раскрытие, главный объект, подготовка к импакту, -2/0/+2/+5/+8/+14/+26/+55/+100 тиков относительно удара; затем три отдельных кадра с screenFlash=false, impactGlitch=false, screenShake=false. Последний вариант также проверяет ClientEffects.shake(0)==0. Команды проходят диспетчер интегрированного сервера и настоящий FX-пакет. Проверяются права оператора, ограничение первой пятёркой, отсутствие задания разрушения/EndEvent/перезарядки, CAMERA/ASTRAL/skip opt-out.

Кадры сняты с framebuffer, не заменены картинками из стороннего рендера. Визуально проверены главные объекты всех пяти сцен, горизонтальные круги, кадры удара, отключённые помехи и читаемость фаз. На первом прогоне крупная фаза перекрывала кончик копья; перенесена в чёрную полосу, после чего вся пятёрка прогнана заново. В GUI 320×240 вступительное название дополнительно опущено, чтобы не закрывать фигуру персонажа; компактный сценарий повторён. Главные кадры/импакты сохранены в previews/style.

Дополнительные сценарии:

```sh
./gradlew runClient -Pstyleqa -Pstylecompact -Pstyleonly=0
./gradlew runClient -Pstyleqa -Pstyleimpactmovie
```

Compact: физическое окно 960×720, GUI scale 3, строго проверяется эффективный размер 320×240. Проверяются 16 кадров копья, включая подписи и отключение эффектов. В обычном окне 960×540 Minecraft ограничивает GUI scale значением 2 — одно выставление настройки 3 не доказывает проверку малого интерфейса.

Impact movie: 48 кадров на заклинание, от -8 до +39 тиков импакта, всего 240. Ролик собирается из реальных кадров без генерации промежуточных кадров. Это детерминированная выборка возрастов каста, **не FPS-бенчмарк и не проверка синхронизации звука**. QA принудительно удерживает возраст для кадров; в null-аудиобэкенде возможны предупреждения лимита звуковых каналов при повторном пересечении тика удара. В обычном ходе каста возраст не удерживается таким способом.

Среда: Xvfb и Mesa llvmpipe, software OpenGL. Пользовательские GPU/шейдерпаки и удалённая игра несколькими физическими клиентами не проверялись. Отсутствующая в среде библиотека narrator/flite и предупреждение vanilla Sampler2 не являются ошибками модового шейдера. Ошибок компиляции/линковки invocation и падений рендера в свежих прогонах не обнаружено.

### Серверная регрессия

```sh
./gradlew runServer -Pv4pure
```

Свежая загрузка модов через dedicated-server target и 326 717 проверок геометрии колонок, 5 676 710 состояний замены блоков, расписание для 1–240 участников, шесть волн/45 секунд и round-trip пакета EndState. Тест выходит до создания мира. Это **не** новое испытание разрушения десятков миллионов блоков и не живой многопользовательский тест.

### Выпуск

```sh
./gradlew clean build
python3 tools/package_release.py
```

Сборка без QA-флагов; проверяются версия в neoforge.mods.toml, JSON, presence InvocationHud/ImpactDynamics и invocation, отсутствие QA-классов и служебных миров/кэшей/секретов. Три прежних предупреждения Java deprecated API остаются; compile errors нет. Итоговые SHA-256 записаны в SHA256SUMS.txt рядом с загружаемыми артефактами.

Существующее сохранённое generateMissingChunks=false не перезаписывается; в новом конфиге default=true сохранён. Настройки endofall и действующее поведение «Конца всего» не менялись.
